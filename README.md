# R van Engelenhoven — luxe websiteconcept

Dit is een mobielvriendelijke statische website in de stijl van de aangeleverde referentie: donker, wit en goud. Het ronde logo is afkomstig van het aangeleverde logo en heeft een transparante achtergrond.

## Nog nodig voor publicatie
1. Vervang de projectfoto-plaatsaanduidingen door de echte foto's van je bestaande site. Deze waren niet beschikbaar in de aangeleverde bestanden. Gebruik bij voorkeur eigen geoptimaliseerde JPG/WebP-bestanden in `assets/`.
2. Vervang `VUL-HIER-JE-EMAIL-IN` in `index.html` door het juiste e-mailadres.
3. Controleer diensten en teksten op juistheid.
4. Upload de bestanden naar een GitHub-repository en koppel deze aan een statische hostingdienst, bijvoorbeeld Cloudflare Pages.
5. Test de tijdelijke URL vóór je DNS van rvanengelenhoven.nl verandert. Laat bestaande mail-DNS-records ongemoeid.
